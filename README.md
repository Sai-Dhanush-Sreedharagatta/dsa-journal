# dsa-journal

My 90-day DSA journal (13 Nov 2026 - 13 Feb 2027): Java solutions grouped by pattern, with notes, an error log and weekly sprint reviews.

## How this repo is organised

| Path | What goes there |
| --- | --- |
| `src/main/java/dsa/<pattern>/` | One file per problem. Header comment: problem link, pattern, insight, time and space complexity |
| `src/test/java/dsa/<pattern>/` | JUnit tests for the same problems |
| `patterns/` | One page per pattern: trigger signals, template code, canonical problems, pitfalls |
| `error-log.md` | Every miss, tagged by cause |
| `blog/` | Markdown drafts of the weekly posts |
| `sprints/` | One file per weekly sprint: goal, review, next goal |

Link to problems and write your own explanation. Do not paste problem statements or editorials from AlgoMaster.
