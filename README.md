# dsa-journal

My 90-day DSA journal (13 Nov 2026 to 13 Feb 2027): notes, Java solutions, an error log and weekly sprint reviews for the whole AlgoMaster course, in the same order as the course.

## How this repo is organised

| Path | What goes there |
| --- | --- |
| `sections/NN-name/README.md` | Section notes: contents checklist, key ideas, trigger signals, Java template, complexity, traps, self-test |
| `sections/NN-name/<subsection>/<item>/notes.md` | Notes for one lesson or problem |
| `sections/NN-name/<subsection>/<item>/Solution.java` | My accepted solution for that problem |
| `error-log.md` | Every miss, tagged by cause |
| `patterns/` | Cross-section cheat sheets, written near the end |
| `sprints/` | One file per weekly sprint: goal, review, next goal |
| `blog/` | Markdown drafts of the weekly posts |
| `src/` | Maven project with tests (`mvn -B test`), used by the projects |
| `scripts/` | `start.sh`, `log-miss.sh`, `flagged.sh` |
| `docs/NOTES-GUIDE.md` | The note-taking routine |

Start with [sections/README.md](sections/README.md) for the section index and [docs/NOTES-GUIDE.md](docs/NOTES-GUIDE.md) for the routine.

Links to problems and my own explanations only. No pasted problem statements or editorials.
